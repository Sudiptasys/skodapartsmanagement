How to use this format

The month filter at the top of the Dashboard drives everything below it — KPIs, Order Type breakdown, Part Category breakdown, and the Month-wise report all update together when you pick a month.
Use + New Order on the Order Register tab to log a new part order — anyone can add entries.
Once saved, an entry is locked. Only someone logged into the Admin tab can edit a cell or delete a row.
The gold-highlighted Qty Received, Received Date, DMS Receipt No. and DMS Receipt Date columns are the one exception — click the ✎ Update button on any row to fill these in, no Admin login needed. Entering a DMS Receipt No. flips a Received order's Case Status from Open to Closed.
Open = not yet fully received and closed off (covers Invoiced/In-Transit, Ordered, Partially Received, Backorder, and Received-without-DMS-Receipt-No.). Closed = Received with a DMS Receipt No. entered.
Grey cells (Total, Qty Pending, Reorder flag) always calculate automatically — don't type into these.
Use Print / Save as PDF on the Order Register tab for a printable copy for the parts counter.

Note: this page keeps data only for your current browser session — closing the tab clears it. Print or copy out entries you need to keep, or ask for a version with permanent storage.
